# 训练与编码实现 (`moss_small_encoder`)

本模块包含训练集构建、两阶段特征提取与线性投影层求解的实现。ComfyUI 使用方法请参考 [根目录说明](../README.md)。

训练依赖在 `src/requirements.txt`。

## 逐 Token 线性配对原理

MOSS-Image 的扩散模型在生成过程中通过 Cross-Attention 接收 4096 维条件向量。文本编码器在推理时全程冻结，其核心任务是将输入文本编码为连续的逐 Token 隐状态作为引导。

Qwen3.5 全系列模型（0.8B、2B、4B、9B）共享相同的词表与分词逻辑，同一输入提示词在各尺寸模型中具有完全一致的 Token 切分与位置对应。因此，可将映射建模为独立的逐 Token 空间线性变换，无需引入跨 Token 的注意力计算：

```
标准化变换：
z = (h_student - mean_in) / std_in

线性投影变换：
cond = z @ W * std_out + mean_out
```

## 训练数据集构成

数据按输入格式和语料形态进行分桶，覆盖模型在实际生成中常见的场景：

| 数据桶 | 来源类别 | 数据格式 | 说明 |
| --- | --- | --- | --- |
| `layout` | 确定性合成 | MOSS Layout JSON | 覆盖 MOSS 专有的排版语法与坐标表示 |
| `en_tag` | 公开语料 | 英文标签序列 | 覆盖常用 Tag 组合、画风与修饰词 |
| `en_prose` | 公开语料 | 英文连续自然语言 | 增强长句叙事与细节描述的特征对齐 |
| `zh_prose` | 原生中文 | 中文连续自然语言 | 增强原生中文提示词表达 |
| `zh_extra` | 补充中文 | 中文描述语料 | 扩充多领域中文词汇分布 |
| `zh_tag` | 确定性组合 | 中文标签流 | 扩充中文短语标签覆盖 |
| `negative` | 负面提示词 | 常见负向提示词 | 对齐无分类器引导 (CFG) 负向特征空间 |
| `official` | 官方示例 | MOSS 原生样例 | 构建期标为 test；训练端按 `prompt_id` 重新哈希划分，不保证留在 test |
| `hard_cases` | LLM 合成 | 中文提示词 | 构建阶段不产出；由 `merge.py` 的合并步骤并入语料 |

### 数据清洗准则
- **长度过滤规则**：超过 4096 Token 的样本整条剔除，不执行中间截断，避免截断导致半句语义破坏。
- **确定性抽样**：基于 `source_id` 的哈希分布进行稳定抽样，保证数据集构建可完全复现。

## 特征提取与编码流程

为避免在单卡上同时加载教师与学生模型导致显存溢出，特征编码采用两阶段离线处理：
1. **教师特征编码**：加载 9B 教师模型，生成 `teacher.raw`（每 Token 4096 维）。
2. **学生特征编码**：加载对应规格的学生模型，提取 6 层指定隐藏状态并拼接，生成 `student.raw`。

特征与中间状态序列化为二进制文件，并通过记录 Token 偏移量支持断点续跑，防止中断后重复计算。

### 变长打包（`--packed`）

教师遍默认把一批补齐成矩形，批内长度离散度大时，算力有相当一部分烧在 pad 上。
`--packed` 改成把整批首尾相接成一条序列，用 flash-attn 的 varlen 接口一次前向：

- 完整注意力层靠 `cu_seqlens` 分段，线性注意力的 gated delta rule 靠 fla 的
  `cu_seqlens` 重置递推，卷积层靠 `seq_idx` 在段边界断开；
- `position_ids` 与 `seq_idx` 都由 `cu_seqlens` 反推，不单独传参，避免两处不一致；
- 不补 pad，长度离散度那条关批条件失效，预算按真实 token 填满。

依赖三项缺一不可：`flash-attn`、`flash-linear-attention`、`causal-conv1d`。
缺任一项直接报错而不降级：`sdpa` 会忽略 `cu_seqlens`，PyTorch 版 delta rule
不认 `cu_seqlens`，`F.conv1d` 不看 `seq_idx`，三种退化都是静默跨段串味，
结果看起来正常但数值全错。

等价性用极小随机初始化模型对拍验证（长度 1/2/3/50/120）：packed 对逐条单独前向的
余弦分别为 1.00000000 / 0.99999815 / 0.99999440 / 0.99999386 / 0.99999410，
最大绝对差不超过 0.03125（bf16 舍入步长量级）；换掉首条内容后，其余各条输出逐位相同。

以 `--packed` 续跑且目录里已有 `teacher.raw` 时，程序先拿它当基准对拍 20 条（跳过 token 0 这个
attention sink），余弦均值低于 0.9990 或单条低于 0.9950 立即退出，此时写入器尚未打开。
写入器本身也拒绝在缺少续跑记录时覆盖非空文件，直接抛 `FileExistsError`，
不会回落到 `wb` 把已有特征清零。

## 投影层求解

在标准化特征空间内直接求解带 L2 正则化的最小二乘正规方程（Ridge 闭式解）：

$$(X^T X + \lambda I)W = X^T Y$$

- 在验证集上执行正则化系数 $\lambda$ 的对数网格扫描；
- 以最多 5 万验证 token（`--eval-tokens` 默认 50,000）拍平后的整体余弦最大化为指标确定最优线性投影矩阵 $W$；
- 闭式解计算速度快、数值稳定，避免了传统迭代训练中容易出现的梯度震荡与过拟合风险。

## 适配器权重导出格式

导出的适配器权重为标准的单个 `.safetensors` 文件，包含以下张量与参数：

| 键名 | 数据类型 | 形状 / 维度 | 含义说明 |
|---|---|---|---|
| `weight` | float16 | `[d_in, 4096]` | 标准化空间下的线性投影矩阵 |
| `mean_in` / `std_in` | float32 | `[d_in]` | 学生模型输入特征各维度的均值与标准差 |
| `mean_out` / `std_out` | float32 | `[4096]` | 教师模型目标特征各维度的均值与标准差 |
| `sink` | float32 | `[4096]` | 教师模型首 Token (Attention Sink) 的全局校准向量；**可选**，旧适配器可能没有 |
