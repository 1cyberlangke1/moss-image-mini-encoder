# 训练与编码实现 (`moss_small_encoder`)

本模块包含训练集构建、特征提取编码与线性投影层求解的核心实现。ComfyUI 部署使用方法请参考[根目录说明](../../README.md)。

---

## 模块结构概览

```

labels.py         敏感内容与风格启发式标签判定（用于分层抽样与均衡性统计）

encode/           特征提取与编码
  quant.py        safetensors 权重与 comfy_kitchen 量化张量转换
  teacher.py      9B 教师模型加载与前向计算（支持常驻量化并跳过视觉与分类头）

  run.py          两阶段特征抽取流程、断点续跑与序列化存储

  store.py        二进制特征存储格式与 mmap 内存映射读取

  run.py          自动化流水线：超参扫描、训练求解与权重导出
```

## 逐 Token 线性配对原理

MOSS-Image 的文本编码器并不执行自回归文本生成，而是将输入文本编码为连续的逐 Token 隐状态，传递给 42 层 DiT 主干进行交叉注意力（Cross-Attention）计算。

由于 Qwen3.5 全系列模型（0.8B、2B、4B、9B）共享相同的词表与分词逻辑，同一输入提示词在各模型中具有完全一致的 Token 切分与位置对应。因此，可将映射建模为独立的逐 Token 空间线性变换，无需引入跨 Token 的注意力计算：

```
标准化变换：
z = (h_student - mean_in) / std_in

线性投影变换：
cond = z @ W * std_out + mean_out
```

## 训练数据集构成

数据按输入格式和语料形态进行分桶，覆盖模型在实际生成中常见的场景：

| 数据桶 | 来源类别 | 数据格式 | 说明 |
| --- | --- | --- | --- |
| `layout` | 确定性合成 | MOSS Layout JSON | 补全 MOSS 专有排版语法覆盖 |
| `en_tag` | 公开语料 | 英文标签序列 | 覆盖常用 Tag 组合与修饰词 |
| `en_prose` | 公开语料 | 英文连续自然语言 | 增强长句叙事与细节描述表征 |
| `zh_prose` | 原生中文 | 中文连续自然语言 | 增强原生中文提示词表达 |
| `zh_extra` | 补充中文 | 中文机器翻译扩展 | 扩充多领域中文词汇分布 |
| `zh_tag` | 确定性组合 | 中文标签流 | 扩充中文短语标签覆盖 |
| `negative` | 负面提示词 | 常见负向提示词 | 对齐无分类器引导 (CFG) 特征空间 |
| `official` | 官方示例 | MOSS 原生样例 | **仅作为独立验证集**，不参与训练拟合 |

### 数据清洗准则
- **长度截断规则**：严格过滤超过 4096 Token 的超长样本，不执行粗暴截断，保证长序列上下文边界的完整性。
- **确定性抽样**：基于 `source_id` 的哈希分布进行稳定抽样，保证数据集构建的完全可复现性。

## 特征提取与编码流程

为降低显存峰值开销，特征编码分为两阶段串行执行：
1. **教师特征编码**：加载 9B 教师模型，生成 `teacher.raw`（每 Token 4096 维）。
2. **学生特征编码**：加载对应规格的学生模型，提取 6 层指定隐藏状态并拼接，生成 `student.raw`。

特征与中间状态序列化为二进制矩阵文件，并通过记录 Token 偏移量实现断点续跑，防止中断后数据污染。

## 投影层求解

在标准化特征空间内直接求解正则化最小二乘（Ridge 闭式解）：

$$(X^T X + \lambda I)W = X^T Y$$

- 在验证集上执行正则化系数 $\lambda$ 的对数网格扫描。
- 以逐 Token 余弦相似度最大化作为评价指标，确定最优线性投影矩阵 $W$。
- 闭式解计算快速、数值稳定，且无传统迭代训练容易出现的局部极值或过拟合问题。

## 适配器权重导出格式

导出的适配器权重为标准的 `.safetensors` 文件，主要包含以下张量与元数据：

| 键名 | 数据类型 | 形状 / 维度 | 含义说明 |
|---|---|---|---|
| `weight` | float16 | `[d_in, 4096]` | 标准化空间下的线性投影矩阵 |
| `mean_in` / `std_in` | float32 | `[d_in]` | 学生模型输入特征各维度的均值与标准差 |
| `mean_out` / `std_out` | float32 | `[4096]` | 教师模型目标特征各维度的均值与标准差 |
| `sink` | float32 | `[4096]` | 教师模型首 Token (Attention Sink) 的全局均值校准向量 |

文件 Header 的 `metadata` 中附带输入层抽头索引 `taps`、最优正则系数 `alpha` 等配置，以便 ComfyUI 节点自适应解析。
